# Qwen3.8-27B：旋转三值 QAT 教学

学习如何把402个矩阵量化为三值，再通过训练恢复。这里是Bonsai风格的独立教学实现，尚未完整复现官方训练配方。

**只想下载模型提问？直接看[27B部署步骤](../../docs/DEPLOYMENT.md#27b)。**

## 当前状态

| 版本 | 已完成 | 尚待完成 |
|---|---|---|
| [32步公开版](https://huggingface.co/aden1350/Qwen3.8-27B-BonsaiStyle-Ternary-QAT-Experimental/tree/qat-step32) | 压缩导出、完整检查点恢复、独立八提示生成 | 整体质量恢复；新自定义提问入口GPU复验 |
| 96步候选版 | 追加64步，81.34GB检查点保存与实际恢复，约5.85GB压缩重载前向一致 | 首题触发显存保护，生成完成0/8；等待空闲卡补测，尚未发布 |

**两版都未通过整体质量验收。** 32步版仍有概念和指令遵循退化；96步的损失下降不能代替生成验证。当前参考推理约0.69 token/s，不适合日常聊天：每个token重复解包完整权重矩阵，尚无融合低比特内核；增加训练步数不会自动加速。

## 按这个顺序学习

| 阶段 | 要做什么 | 入口 |
|---|---|---|
| 1. 小规模机制 | 验证旋转、三值打包、STE与检查点 | [CPU实验](GUIDE.md#mechanisms) |
| 2. 原始模型 | 校验固定版本与资源预算 | [模型准备](GUIDE.md#source) |
| 3. 32步训练 | WikiText蒸馏、磁盘梯度、导出与恢复 | [训练步骤](GUIDE.md#train32) |
| 4. 96步续训 | 恢复旧32步状态，追加中英文上下文训练 | [续训步骤与限制](GUIDE.md#continue96) |

全模型训练使用Linux、单张空闲5090、大容量主机内存及本地磁盘；训练资源远大于压缩权重体积。先按指南检查预算，再运行GPU命令。
