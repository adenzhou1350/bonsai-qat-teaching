# 动手课程：从方程到独立验证

按顺序完成下面四课。每课都写下输入、实际命令、输出及结论范围；运行环境与完整命令见 [复刻步骤](REPRODUCING.md)。这些练习使用已有代码，不需要实验服务器上的私有目录或访问凭证。

## 第一课：CPU 上理解三值训练

安装根目录依赖后，在 Linux 终端运行：

```bash
CUDA_VISIBLE_DEVICES='' python test_equations.py
```

无需模型、数据或 GPU。对照 [quantization.py](../quantization.py) 与 [test_equations.py](../test_equations.py) 阅读实际断言：

| 观察 | 要解释的问题 |
|---|---|
| 编码只含 −1、0、1，尺度为 BF16 | 三值编码和浮点尺度分别保存什么？ |
| 打包再解包恢复原编码，131 列也通过 | 为什么 5 个三值占 1 字节，还需要保存原始形状？ |
| STE 梯度等于传入梯度 | 前向离散化后，FP32 主权重怎样收到梯度？ |
| 分块 KL 的值和梯度与完整计算一致 | 分块节省临时空间，为什么没有减少监督位置？ |
| 恢复后的下一步参数和 Adam 状态一致 | 只保存量化权重为什么不足以继续同一训练？ |
| 损坏文件被拒绝且参数未变 | 检查点应当在修改模型前完成哪些检查？ |

最后应输出 `PASS: ternary grid, identity STE, packing, ...`。这课证明小规模方程与恢复语义；整模型数值、训练稳定性及能力仍需分别验证。

## 第二课：从自己的文本完成 35B 两步训练

准备原始 Qwen3.5-35B-A3B、本地 `texts.jsonl` 和 2×B300，按 [35B 命令](REPRODUCING.md#35b全专家权重qat) 依次运行 `prepare_data.py`、`prepare_teacher.py`、`train.py --steps 2`。数据不足会报错；教师默认仍生成完整 TRAIN/VAL，准备成本不会因两步控制消失。

运行前回答：这次更新的是 80 个完整专家张量，还是低秩补偿？根目录答案是前者。运行后核对步数、完整 VAL 条数、80 个导出矩阵和逐文件 SHA，再保存实际环境及输入身份。

两步正常退出后，才按同页命令启动 4096 步。将完整检查点保存到独立磁盘预算内；恢复使用 `--resume` 和新输出目录。CPU 课程已经测试下一步恢复一致，整模型跨设备拓扑的恢复不在已验证范围内。

自己的 JSONL 可以复刻训练机制。原实验数据修订、采样清单和独立评分流水线尚未完整发布，因此它不能复制实验表中的能力数字。

## 第三课：学习如何判定一次训练

阅读 [35B](experiments/35B.md) 和 [122B](experiments/122B.md)，对每条路线分别回答四个问题：

1. **训练完成了吗？** 计划更新数、正常退出、完整导出是否都有证据？
2. **产物重载正确吗？** 新进程是否加载同一 manifest，全部验证行和冻结参数身份是否核对？
3. **能力保持了吗？** 同题集、同生成与评分设置下，是否达到预先规定的原模型门槛？
4. **部署测量说明什么？** 是单请求解码还是服务吞吐，计时是否包含预填充，权重是否全部驻留 GPU？

可用 122B native4095 做练习：训练目标显著下降、独立重载通过、单张 5090 能解码，但四组公开开发评测均略低于原模型。四个问题会得到不同答案。35B 第二轮平均目标下降而 NLL 略升，也应把两个指标分别保留。

学习推理适配时，再读 [失败与修复](experiments/INFERENCE.md)：文件身份相同仍可能因 dtype、卷积后端、缓存或运算顺序产生差异。定位时先比较相同输入的逐层结果，再看整模型和能力。

## 第四课：运行已完成的 122B 产物

已有对应 packed 权重时，执行 [experimental122 的实际命令](../experimental122/README.md)。先固定 `old` 或 `native4095` 及 manifest SHA，再运行自然生成和固定步数测速。原始 BF16 权重不能代替 packed 产物。

记录五档上下文的解码时间、Graph/静态 token ID 对照、峰值显存与计时边界。单卡约 19–29 tokens/s 来自已经完成的特定 MoE 产物和测量设置；不能推广成所有百 B 模型的速度。

当前仓库没有分发这些权重，也还没有发布从原始 122B 完成全流程的可执行课程。这课在没有对应权重时只能阅读记录；可移植链路的缺口见 [P122](experiments/122B.md#p122从原始模型重新生成的可移植课程)。
