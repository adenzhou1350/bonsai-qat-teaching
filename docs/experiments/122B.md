## dense 校准数据身份已核对

已沿 seed manifest 和 lineage 找到实际校准语料及 token 文件。dense 校准使用固定版本的 CodeAlpaca 公开参考回答与自编算术：选取 512 个 TRAIN 块、16 个 VAL 块，每块 513 token，前 512 位置输入；只有 TRAIN 更新 Hessian。实际选中 TRAIN 文档中 2113 条代码、550 条数学，VAL 中 51 条代码、49 条数学；文档会拼接成 token 块，因此这些文档数不同于块数。记录包含修订、文件及 token SHA，见[数据身份](122B-dense-data-provenance.json)。

这是原始 BF16 隐藏状态的重建校准，参考回答来自公开/自编文本；不是原模型生成这些回答，也不是后续恢复训练的 OpenThoughts 数据。元数据记录 CodeAlpaca 为 Attribution-NonCommercial 4.0 International，不把这份语料描述成无限制商业许可。完整选择与序列化的[数据重建课程](../../courses/122b/README.md)现已发布，实际 CPU 运行逐字节重建 5224 条对话，全部 270864 个 token ID 一致；这一步不能替代完整可移植训练完成。

全 48 层 dense 校准的实际 CLI 及独立逐项审计已完成，见[01:50 完成记录](2026-10-10-0150.json)。此节点不等于完整教师生成或恢复训练完成。

完整 seed 已完成且退出 0，96 expert + 373 dense bank、embedding4/rank16、361 个保留参数与参考值一致，831 个源参数身份一致，见[02:18 组装证据](2026-10-10-0218.json)。完整 4224 条教师生成、恢复训练与新产物推理尚未完成，相关等待流程已停止。
