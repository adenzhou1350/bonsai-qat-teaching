## 记录约定

每个实验写清模型/权重 SHA、训练对象、数据、命令对应代码、资源、数值检查、能力结果与限制。新结果写入对应文档和新的日期快照；旧失败保留，不把所有进度追加到 README。

学习时按 [动手课程](../LABS.md) 执行；新实验复制 [记录模板](TEMPLATE.md)。后续节点以相同产物身份补充证据，旧快照不改写成后来的状态。

“可运行”需要真实命令与正常退出；“可复刻训练”还需从公开说明的输入完成导出与独立重载；“质量通过”需要预先约定的能力标准。AST 相同、文件 SHA 一致、负例拒绝、损失降低和 tokens/s 都分别记录。

公开开发题不用于梯度训练；评分上限和分母保持不变。保留测试在开发门槛通过前关闭，失败分支不通过改阈值宣称成功。当前没有已通过完整能力验收的量化候选。
