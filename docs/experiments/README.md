## 记录约定

学习按[动手课程](../LABS.md)执行；新实验使用[记录模板](TEMPLATE.md)，写清模型与权重身份、训练对象、数据、代码、资源、数值检查、能力结果和限制。新结果进入对应路线文档和日期快照，时间线只保留过程，旧快照不改写成后来的状态。

“可运行”需要真实命令和正常退出；“可复刻训练”还需从公开说明的输入完成导出与独立重载；“质量通过”需要预先约定的能力标准。文件或代码相同、数值一致、损失降低、吞吐改善，各自回答不同的问题。

公开开发题不用于梯度训练，评分上限与分母保持原值。保留测试在开发门槛通过前关闭，不通过改阈值把失败分支写成成功。
