# 实验记录模板

复制本页后填写。未运行、排队中、运行中、正常完成、失败分别标明；没有执行的检查填写“未验证”，不要填 0 或通过。

## 问题与方法

- 实验 ID、记录时间与待验证问题：
- 模型名称、总参数/激活参数、原始修订与文件 SHA 清单：
- 仓库 commit、入口命令、环境版本与实际计算后端：
- 量化格式、group size、尺度 dtype、训练参数与冻结参数：
- 相对于对照只改变了什么；为什么改变：
- GPU/CPU/内存/磁盘需求：

## 数据与训练

- 数据名称、修订、预处理/采样 seed 与精确样本清单：
- TRAIN/VAL 来源划分、重复与评测污染检查：
- token 文件、tokenizer 与教师目标身份；师生位置和输出头：
- 优化器、学习率、裁剪、计划/实际步数、恢复来源：
- 实际开始/结束时间、退出码、导出 manifest SHA：

写清能证明什么、不能证明什么、失败原因是否已证实，以及其他人复刻还缺哪些文件。保留测试须遵守预先声明的开发门槛。公开仓库只放脱敏后的证据；不要把凭证、服务器入口、私有原始数据或大权重提交进去。
