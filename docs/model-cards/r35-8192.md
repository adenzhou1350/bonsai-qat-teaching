# Qwen3.5-35B-A3B · INT2 + rank16 · 8192步

35B总参数、约3B激活的MoE。冻结INT2专家基座，训练rank16补偿8192步。**提供单卡5090终端聊天入口。**

| 下载体积 | 单卡参考 |
|---|---|
| 约15.86GB | 历史短上下文/4K热解码约59.33/49.85 token/s；4K峰值约15.61GiB allocated |

速度来自历史固定64步Graph热解码，即使遇EOS也继续，不含加载、编译或预填充；新便携入口尚未GPU复验。三款模型的测试口径不同，见[速度与部署说明](https://github.com/adenzhou1350/bonsai-qat-teaching/blob/main/docs/DEPLOYMENT_REFERENCE.md)。

## 开始使用

需要Linux、Python3.12和一张空闲32GB RTX5090。[完整部署与模型选择](https://github.com/adenzhou1350/bonsai-qat-teaching/blob/main/docs/DEPLOYMENT.md#35b)。

<details>
<summary>首次使用：安装环境</summary>

```bash
git clone https://github.com/adenzhou1350/bonsai-qat-teaching.git
cd bonsai-qat-teaching
git checkout 0664e61bcf41f46d88a5d3fe5f6e07af125853e0
python3.12 -m venv .venv-inference
source .venv-inference/bin/activate
python -m pip install --upgrade pip wheel setuptools packaging ninja
python -m pip install torch==2.11.0 --index-url https://download.pytorch.org/whl/cu130
python -m pip install -r requirements-inference.txt
python -m pip install causal-conv1d==1.7.0 --no-build-isolation
nvidia-smi
```

35B/122B卷积扩展需要兼容的CUDA编译工具链；这里固定记录版本，仍需在目标机器完成实际生成检查。

</details>

从教学仓库根目录运行：

```bash
hf download aden1350/Qwen3.5-35B-A3B-INT2-Rank16-8192-Experimental \
  --revision recovery-step8192 --local-dir models/r35-8192
python experimental35/infer.py --model models/r35-8192/packed --verify-only
CUDA_VISIBLE_DEVICES=0 python experimental35/infer.py \
  --model models/r35-8192/packed --chat --context 4096 --max-new-tokens 256
```

`/reset`清空对话，`/exit`退出。单次提问把 `--chat` 换成 `--prompt '你的问题'`。更长输入可改 `--context 8192` 或 `16384`，会增加显存与等待；单进程串行使用。

## 使用边界

历史8192步产物已完成独立重载与5090 Graph验证；新便携入口的GPU复验仍待完成。CMMLU/GSM8K开发成绩低于原模型，不能宣称整体质量恢复。这是补偿训练，与T35全专家QAT不同。

本项目是独立Bonsai风格文本实验，使用自定义格式，不能直接加载到标准Transformers、vLLM或llama.cpp。性能数字来自历史测量，非新入口端到端吞吐；[显存、上下文与测速说明](https://github.com/adenzhou1350/bonsai-qat-teaching/blob/main/docs/DEPLOYMENT_REFERENCE.md)。
