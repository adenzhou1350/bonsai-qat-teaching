# Qwen3.5-122B-A10B · 三值 + rank8

122B总参数、约10B激活的MoE。三值专家 + 4bit稠密层/embedding，冻结基座训练rank8补偿4096步。**单卡5090的大MoE压缩实验。**

| 下载体积 | 单卡参考 |
|---|---|
| 约30.20GB | 历史短请求CLI约21.72–24.00 token/s；常驻权重约28.10GiB |

21.72与24.00分别来自原预填充和`grouped-prefill16`候选的历史CLI四轮对照，包含请求预填充；不是当前`infer_hf.py`的新增实测，也不能和35B固定热解码直接算加速比。[速度与部署说明](https://github.com/adenzhou1350/bonsai-qat-teaching/blob/main/docs/DEPLOYMENT_REFERENCE.md)。32GB卡余量较小。

## 开始使用

需要Linux、Python3.12和一张空闲32GB RTX5090。[完整部署与模型选择](https://github.com/adenzhou1350/bonsai-qat-teaching/blob/main/docs/DEPLOYMENT.md#122b)。

<details>
<summary>首次使用：安装环境</summary>

```bash
git clone https://github.com/adenzhou1350/bonsai-qat-teaching.git
cd bonsai-qat-teaching
git checkout 0664e61bcf41f46d88a5d3fe5f6e07af125853e0
python3.12 -m venv .venv-inference
source .venv-inference/bin/activate
python -m pip install --upgrade pip wheel setuptools packaging ninja
python -m pip install torch==2.11.0 --index-url https://download.pytorch.org/whl/cu130
python -m pip install -r requirements-inference.txt
python -m pip install causal-conv1d==1.7.0 --no-build-isolation
nvidia-smi
```

35B/122B卷积扩展需要兼容的CUDA编译工具链；这里固定记录版本，仍需在目标机器完成实际生成检查。

</details>

从教学仓库根目录运行：

```bash
hf download aden1350/Qwen3.5-122B-A10B-Ternary-Rank8-Experimental \
  --revision native4095-step4096 --local-dir models/r122
python experimental122/infer_hf.py --model models/r122/packed --verify-only
CUDA_VISIBLE_DEVICES=0 python experimental122/infer_hf.py \
  --model models/r122/packed --prompt '请用中文解释模型量化。' \
  --max-new-tokens 128 --output outputs/r122-first.json
```

先用短问题、单请求，输出文件用新名字。公开包须用 `infer_hf.py`；旧 `infer.py` / HTTP入口固定另一份清单，不能直接加载本包。

## 使用边界

历史产物已完成5090推理，四组开发评测仍低于BF16基线。公开包的471张量通过CPU身份检查，未增加新的GPU复验或质量结论。

本项目是独立Bonsai风格文本实验，使用自定义格式，不能直接加载到标准Transformers、vLLM或llama.cpp。性能数字来自历史测量，非新入口端到端吞吐；[显存、上下文与测速说明](https://github.com/adenzhou1350/bonsai-qat-teaching/blob/main/docs/DEPLOYMENT_REFERENCE.md)。
